☁ Banco de Dados na Nuvem (Supabase)

Preencha os dois campos abaixo para salvar seus dados na nuvem. Assim eles ficam disponíveis em qualquer computador ou celular, e não se perdem se você limpar o navegador.

📘 Como conseguir esses dados (5 minutos, de graça)

1. Acesse supabase.com e crie uma conta grátis (pode entrar com o Google).
2. Clique em New Project, dê um nome (ex.: controle-equipamento), crie uma senha e escolha a região South America (São Paulo). Aguarde ~2 minutos.
3. No menu lateral vá em SQL Editor, cole o código abaixo e clique em Run:
create table controle_equipamento ( board text primary key, dados jsonb not null, data text, hora text, atualizado_em timestamptz default now() ); alter table controle_equipamento enable row level security; create policy "acesso total" on controle_equipamento for all using (true) with check (true);
4. Vá em Project Settings → API. Copie o Project URL para o primeiro campo e a chave anon public para o segundo campo aqui em cima.
5. Clique em Conectar e Salvar. A bolinha no topo fica verde quando estiver funcionando.
⚠ Sobre segurança: a regra acima libera leitura e escrita para qualquer pessoa que tenha o link do seu projeto e a chave pública — é o jeito mais simples de pôr no ar, mas não protege os dados. Se este painel for compartilhado fora da sua equipe, ou se os dados forem sensíveis, o certo é ativar login (Supabase Auth) e trocar a regra por uma que exija usuário autenticado. Me avise que eu preparo essa versão com tela de login.
💡 Dica: mesmo com a nuvem ligada, o app continua guardando uma cópia local. Se a internet cair, você segue trabalhando normalmente e as alterações sobem quando a conexão voltar. Ainda assim, use o Exportar Backup de vez em quando.
